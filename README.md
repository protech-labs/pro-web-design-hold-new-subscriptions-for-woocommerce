# Pro Web Design Hold New Subscriptions for WooCommerce

![Hold New Subscriptions for WooCommerce](https://ps.w.org/pro-web-design-hold-new-subscriptions-for-woocommerce/assets/banner-1544x500.png)

Hold newly created WooCommerce Subscriptions until the parent order reaches a status you choose,
then activate them automatically.

By default, WooCommerce Subscriptions activates a new subscription as soon as checkout completes —
even if the store still needs to review, verify or fulfil the order first. This plugin keeps the new
subscription On-hold (or Pending) until its parent order reaches a status you choose — Completed by
default — and then switches it to Active.

## Features

- Puts new subscriptions on On-hold or Pending right after checkout
- Activates the subscription when the parent order reaches any of the order statuses you select
- Works with new subscriptions only: renewal orders and renewal payments are never touched
- Can be limited to specific payment gateways
- Optional subscription notes and WooCommerce log entries for every action the plugin takes
- Optional customer emails: one when a subscription is placed on hold, one when it is activated
- Works with WooCommerce High-Performance Order Storage (HPOS)

## Installing

Install from the WordPress plugin directory — search for "Pro Web Design Hold New Subscriptions",
or download it here:

**https://wordpress.org/plugins/pro-web-design-hold-new-subscriptions-for-woocommerce/**

Requires WordPress 5.8 or newer, PHP 7.2 or newer, WooCommerce and WooCommerce Subscriptions.
WooCommerce Subscriptions is a separate paid extension sold by WooCommerce.
